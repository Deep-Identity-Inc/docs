```
POST /v1/igaming/ip-jurisdiction
```

Resolves the applicant's IP address to a jurisdiction (via MaxMind GeoLite2) and evaluates it against the session's `ip-jurisdiction` step configuration — allowed/blocked jurisdiction lists, plus optional datacenter-IP handling. Persists its result to the session.

<Note>
  This check fails **soft**. If an internal error occurs, or the supplied
  `ip_address` isn't a valid IPv4 address, it returns `200` with
  `verdict: "UNAVAILABLE"` and `action: "allow"` rather than blocking or
  erroring.
</Note>

## Request

### Headers

| Header         | Required | Description        |
| -------------- | -------- | ------------------ |
| `x-api-key`    | Yes      | Your API key       |
| `Content-Type` | Yes      | `application/json` |

### Body parameters

Bodies use **snake_case** field names — there are no camelCase aliases.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `session_id` | string | Yes | The session to score |
| `ip_address` | string | Yes | The applicant's public **IPv4** address. A non-IPv4 value returns `UNAVAILABLE` (fails soft to `allow`) |

## Response

### 200 — Success

| Field | Type | Description |
| --- | --- | --- |
| `verdict` | string | `HIT`, `CLEAR`, or `UNAVAILABLE` |
| `action` | string | `allow`, `flag`, `step-up`, or `block` |
| `evidence` | object | Details behind the verdict — includes `matchedRule` and `locationDetails.countryIsoCode` |
| `escalation` | object \| null | `{ decision: "ESCALATE", type: string, reason: string }` — present only when `action` is `step-up` |

### Verdicts

| Verdict | Meaning |
| --- | --- |
| `HIT` | The IP resolved to a blocked jurisdiction, or matched the datacenter rule |
| `CLEAR` | The IP's jurisdiction is allowed |
| `UNAVAILABLE` | The step isn't configured on the workflow, or the IP wasn't valid IPv4 — fails soft to `allow` |

### Error responses

| Status | Description |
| --- | --- |
| `400 Bad Request` | Invalid request body — check required fields |
| `401 Unauthorized` | Missing or invalid API key |
| `404 Not Found` | Session not found, or not in your org |
